# 🍫 Double C* Roadmap

This document outlines planned features, improvements, and long‑term goals for the Double Chocolate Cone (Double C*) language.

---

## ✅ Phase 1 — Core Language (Current)
- Basic syntax (entities, scenes, events)
- Variables and expressions
- Built‑in actions (move, jump, rotate, spawn)
- EBNF grammar definition
- Example scripts
- Official language specification

---

## 🚧 Phase 2 — Compiler
- Lexer
- Parser
- AST builder
- Double C* → JavaScript transpiler
- Error reporting
- Runtime API bindings

---

## 🚀 Phase 3 — DC* Studio Integration
- Script editor with syntax highlighting
- Beginner mode (simple commands)
- Advanced mode (full language)
- Scene editor (2D + 3D)
- Live preview
- Asset manager

---

## 🌐 Phase 4 — Playground Website
- Online Double C* editor
- Encode → Double C*
- Decode → JavaScript
- Obfuscator
- Beautifier
- Script database
- Shareable links

---

## 🏗️ Phase 5 — Engine Expansion
- Physics API
- Animation API
- Audio API
- UI system
- Networking

---

## 🏆 Phase 6 — GitHub Linguist Integration
- Submit Double C* language definition
- Add `.dc*` extension
- Assign official color
- Enable GitHub language statistics

---

## 🔮 Phase 7 — Long‑Term Goals
- Package manager (ConePack)
- Module system
- Type system (optional)
- Debugger
- Performance profiler
- Community extensions
